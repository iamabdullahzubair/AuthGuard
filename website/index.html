How to test the dual flow:

  1. Click Enable 2FA above to display the setup QR code.
  2. Open the Authenticator PWA (in another tab, window, or phone).
  3. In the PWA, go to Scan, allow camera access (or upload a screenshot of the QR).
  4. The PWA automatically registers push, creates non-extractable keys, and displays a live 6-digit TOTP code.
  5. Type the 6-digit TOTP code into the website modal to complete activation and save your 10 recovery codes.
  6. Log out and log back in: the website will display a 2-digit number challenge and send a push notification to your PWA!
